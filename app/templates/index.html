🔒

Suas chaves ficam no seu ambiente. São criptografadas no banco de dados e nunca são devolvidas à interface. O OpenStudy não fornece nem compartilha chaves de API.

ⓘ

Atenção à privacidade: ao usar Gemini, OpenAI, Claude ou Groq, o texto dos documentos e as perguntas necessárias à tarefa serão enviados à API do provedor escolhido. Se preferir que o processamento de linguagem permaneça no computador, selecione Ollama. Os embeddings e a busca semântica permanecem locais via Ollama; sem ele, o sistema usa busca textual como alternativa.
